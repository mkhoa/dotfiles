# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

A **chezmoi source directory** holding the user-owned layer of a [Ryoku](https://ryoku.dev) desktop (Hyprland in Lua plus Ryoku's Quickshell bar, dock and Hub). There is nothing to build or test. "Correct" means the live desktop looks and behaves as intended.

Branches: **`ryoku`** is the current machine. `main` is the old CachyOS + Noctalia setup, kept for reference. Do not port Noctalia-era files onto `ryoku`.

Published as `mkhoa/dotfiles` on GitHub (`origin`).

## The rule: track only what Ryoku leaves to the user

Ryoku ships the desktop as packages and `ryoku materialize` re-lays every shipped file on each `ryoku update`. If chezmoi also tracks one of those files, the two overwrite each other. So before adding or editing any path, run:

```bash
ryoku owner ~/.config/<path>
```

| `class` | Track here? | Where a change goes |
|---|---|---|
| `ryoku` | No | Fork it to `~/.config/ryoku/user_edits/<same path>` and track the fork |
| `generated` | No | The Hub page or command that writes it |
| `store` (`~/.config/ryoku/*.json`) | No | `ryoku-shell` / `ryoku-hub` / `ryogami`, the one writer |
| `seed`, `user-override`, `overlay`, `user` | Yes | Edit in place |

The machine-wide map is `~/.local/share/ryoku/rashin/ownership.md`. Read `~/.local/share/ryoku/rashin/AGENTS.md` and the `ryoku` skill before changing the desktop.

Notable cases:

- `hypr/user.lua` is the place for raw Hyprland Lua the Hub doesn't expose. It loads last and wins.
- `hypr/monitors.lua` is regenerated by the Hub's Displays page. Manual pins go in `hypr/monitors_user.lua`.
- `ryoku/user_edits/hypr/{settings,settings_window,rebinds}.lua` are written by Ryoku Hub. They are tracked as a backup only: change them in the Hub, then `chezmoi re-add`. Never hand-edit them.
- Files with `ryoku-colors` in the name, and `yazi/theme.toml`, are palette outputs from the theme daemon. Don't track them.

## Workflow

```bash
chezmoi status                            # col 1: source ahead (apply); col 2: live ahead (re-add)
chezmoi re-add                            # pull Hub/app changes into the repo
chezmoi diff -- ~/.config/hypr/user.lua   # preview one file
chezmoi apply ~/.config/hypr/user.lua     # apply one file
```

Scope `apply` to the file you changed. Hub-written files may be newer live than in the repo.

Reload Hyprland with `ryoku wm act config.reload`. A reload that succeeds only means the config parsed. Confirm binds with `hyprctl binds -j` (Lua binds show `dispatcher: __lua`, so match on `modmask` + `key`; SUPER = 64).

## Conventions

Commits are **one concern each**, subject-only unless the reasoning is non-obvious, written in plain-English imperative describing the visible outcome ("Make unfocused windows 90% opaque"). No conventional-commit prefixes, no scopes.

Comments in Lua configs explain *why* a line exists, and stay sparse.
